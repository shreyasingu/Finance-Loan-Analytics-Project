
# Finance Loan Analytics Project

## Project Overview

This project analyzes bank loan customer data using multiple technologies:

- Power BI
- Tableau
- Python
- SQL

The same business problem was solved using different analytics tools to demonstrate data analysis, visualization, and reporting skills.

## Domain

Finance

## Dataset

- Finance1.csv
- Finance2.csv
- 39,000+ records per dataset

## KPIs

1. Year Wise Loan Amount Analysis
2. Grade & Sub-Grade Wise Revolving Balance Analysis
3. Verified vs Non-Verified Payment Analysis
4. State Wise & Month Wise Loan Status Analysis
5. Home Ownership vs Last Payment Date Analysis

## Tools Used

- Power BI
- Tableau
- Python (Pandas, Matplotlib, Plotly)
- SQL

## Key Insights

- Verified customers generated higher payment amounts.
- Loan distribution varied significantly across states.
- Revolving balance differed across grades and sub-grades.
- Loan status trends changed across months.
- Home ownership showed relationships with repayment patterns.
